# Support

Giro is preparing for its first public open-source release.

## Getting Help

Use GitHub issues for:

- Setup questions.
- Documentation gaps.
- Bug reports.
- Feature requests.
- Architecture questions.

Before opening an issue, check:

- [README.md](README.md)
- [docs/developer-guide.md](docs/developer-guide.md)
- [docs/architecture.md](docs/architecture.md)
- [docs/api.md](docs/api.md)
- [docs/product.md](docs/product.md)

## Security

Do not report vulnerabilities in public issues. Follow [SECURITY.md](SECURITY.md). GitHub private vulnerability reporting should be enabled before the first public release.

## Maintainer Contact

Public alpha maintainer contact is not yet published. Until then, use GitHub issues for non-sensitive support and avoid sharing secrets, exploit details, or private repository data.
